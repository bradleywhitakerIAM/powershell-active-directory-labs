# Project 3: Active Directory Employee Transfer

## Project Overview

Simulated an employee department transfer using Windows Server 2022, Active Directory, and PowerShell.

This project demonstrates the Mover stage of the Joiner-Mover-Leaver (JML) identity lifecycle.

### Scenario

Ticket: IAM-2026-003

Employee: Michael Torres (fictional)

Previous Department: Finance

New Department: Human Resources

Previous Role: Financial Analyst

New Role: HR Specialist

### IAM Skills Demonstrated

- Identity lifecycle management (JML)
- Active Directory user attribute updates
- Security group membership management
- Access provisioning and deprovisioning
- Organizational Unit (OU) transfers
- Role-Based Access Control (RBAC)
- Least privilege
- Post-change access verification

### Project Status

Technical lab completed. Audit documentation in progress.
