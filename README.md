# powershell-active-directory-labs
Hands on PowerShell labs for Active Directory administration, identity management, access auditing, and IAM operations.



## Completed IAM Lab Projects

### Project 1: Disabled Active Directory Account Audit

**Objective:** Identify disabled Active Directory
accounts using PowerShell as part of a simulated
IAM access review.

**Environment:** Windows Server 2022,
Active Directory, PowerShell

**Skills demonstrated:**
- Active Directory user account auditing
- PowerShell filtering and reporting
- Identity lifecycle review
- Security audit documentation

**Results:** Identified five disabled accounts in
a controlled lab environment, including three
fictional employee accounts and two built-in
Active Directory accounts.

**Project files:**
- [View PowerShell Script](01-user-management/Get-DisabledADUsers.ps1)
- [View IAM Audit Report and Screenshot](01-user-management/Disabled-Accounts-Audit.md)

**Status:** Completed lab exercise with documented
command execution and screenshot evidence.
